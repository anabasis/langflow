# Render에 Langflow 배포하기
> 원문: https://docs.langflow.org/next/deployment-render

이 가이드는 웹 애플리케이션과 API를 배포하기 위한 클라우드 플랫폼인 [Render](https://render.com/)에 Langflow를 배포하는 방법을 설명합니다.

1. Langflow를 지원할 수 있는 Render 인스턴스를 준비하세요.

    Langflow를 실행하려면 최소 2GB의 RAM이 필요하므로, **Standard** 이상의 Render 인스턴스 유형을 사용해야 합니다.
이를 위해서는 유료 Render 계정이 필요합니다.
자세한 내용은 [Render Web Services](https://render.com/docs/web-services)와 [Render 가격 정책](https://render.com/pricing)을 참조하세요.

2. 다음 링크를 따라 Render에서 Langflow 배포를 시작하세요.

    [![Deploy to Render]()](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2Flangflow-ai%2Flangflow%2Ftree%2Fdev)

3. 블루프린트 이름을 입력하고, `render.yaml` 파일의 브랜치를 선택한 다음 **Deploy Blueprint**를 클릭하세요.

배포가 완료되면 Langflow 인스턴스를 바로 사용할 수 있습니다.
