# Railway에 Langflow 배포하기
> 원문: https://docs.langflow.org/next/deployment-railway

이 가이드는 자동 배포, 관리형 데이터베이스, 자동 스케일링을 제공하는 클라우드 인프라 플랫폼인 [Railway에 Langflow를 배포하는 방법](https://railway.com/?utm_medium=integration&utm_source=docs&utm_campaign=langflow)을 설명합니다.

1. Railway 계정을 생성하세요.

    Langflow가 요구하는 듀얼 코어 CPU와 2GB RAM 사양에는 Railway의 Hobby 계정으로 충분합니다. 자세한 내용은 [Railway 가격 정책](https://railway.com/pricing?utm_medium=integration&utm_source=docs&utm_campaign=langflow)을 참조하세요.

2. 다음 링크를 따라 Railway에 Langflow 템플릿을 배포하세요.

    [![Deploy on Railway]()](https://railway.com/new/template/JMXEWp?referralCode=MnPSdg&utm_medium=integration&utm_source=docs&utm_campaign=langflow)

3. 선택 사항: Langflow 배포에 대한 커스텀 설정을 추가하세요.

    Langflow Railway 템플릿은 인프라를 자동으로 구성하고, Langflow를 배포한 뒤 애플리케이션을 시작합니다.

4. 배포가 완료될 때까지 기다리세요.

5. 배포의 공개 URL(예: `https://APP-NAME.up.railway.app`)로 이동해 Langflow 인스턴스에 접속하세요.
