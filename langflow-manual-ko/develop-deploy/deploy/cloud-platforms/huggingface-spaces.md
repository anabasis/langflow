# Hugging Face Spaces에 Langflow 배포하기
> 원문: https://docs.langflow.org/next/deployment-hugging-face-spaces

이 가이드는 [Hugging Face Spaces](https://huggingface.co/spaces/)에 Langflow를 배포하는 방법을 설명합니다.

1. [Langflow Space](https://huggingface.co/spaces/Langflow/Langflow?duplicate=true)로 이동하세요.

2. **Duplicate Space**를 클릭하세요.

3. 복제한 Space를 다음과 같이 구성하세요.

  1. Space의 이름을 입력합니다.
  2. 공개(public) 또는 비공개(private) 가시성을 선택합니다.
  3. **Duplicate Space**를 클릭합니다.

    ![Hugging Face deployment dialog](https://docs.langflow.org/assets/images/hugging-face-deployment-fa1554738ef6c3249ba3fec70b2134cb.png)

설정이 완료되면 새 Space로 자동으로 이동하며, 이제 Langflow 인스턴스를 바로 사용할 수 있습니다.
