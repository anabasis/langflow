# Langflow 커뮤니티 참여하기

> 원문: https://docs.langflow.org/next/contributing-community

Langflow 커뮤니티와 소통하고 Langflow 코드베이스에 대해 더 알아볼 수 있는 여러 방법이 있습니다.

## Langflow Discord 서버 참여하기[​](#join-the-langflow-discord-server "Direct link to Join the Langflow Discord server")

[Langflow Discord 서버](https://discord.gg/EqksyE2EX9)에 참여하여 질문하고 여러분의 프로젝트를 소개해 보세요.

## X에서 Langflow 팔로우하기[​](#follow-langflow-on-x "Direct link to Follow Langflow on X")

X(구 트위터)에서 [@langflow_ai](https://twitter.com/langflow_ai)를 팔로우하여 Langflow의 최신 소식을 받아보세요.

## GitHub에서 Langflow에 별표 남기기[​](#star-langflow-on-github "Direct link to Star Langflow on GitHub")

Langflow가 마음에 드신다면 [Langflow GitHub 저장소](https://github.com/langflow-ai/langflow)에 별표(star)를 남겨주세요.
별표는 다른 사용자들이 Langflow를 더 쉽게 찾을 수 있게 해주고, 다른 사용자들이 이미 유용하다고 느꼈다는 것을 빠르게 알 수 있게 해줍니다.

Langflow는 오픈소스 프로젝트이기 때문에, 저장소의 가시성이 높아질수록 더 많은 [기여자](https://docs.langflow.org/contributing-how-to-contribute)를 끌어들일 가능성이 커집니다.

## GitHub 저장소 watch하기[​](#watch-the-github-repository "Direct link to Watch the GitHub repository")

[Langflow GitHub 저장소](https://github.com/langflow-ai/langflow)를 watch하면 새 릴리스와 기타 저장소 활동에 대한 알림을 받을 수 있습니다.

릴리스 알림만 받으려면 **Releases only**를 선택하세요.

**Watching**을 선택하면 새 릴리스뿐만 아니라 이슈, 토론, 풀 리퀘스트에 관심이 있는 경우 관련 알림도 받게 됩니다.
저장소 알림을 커스터마이징하는 방법에 대한 자세한 내용은 [GitHub 저장소 구독 관련 문서](https://docs.github.com/en/account-and-profile/managing-subscriptions-and-notifications-on-github/managing-subscriptions-for-activity-on-github/viewing-your-subscriptions)를 참고하세요.

## GitHub를 통해 개선 사항을 요청하고 도움 받기[​](#request-enhancements-and-get-help-through-github "Direct link to Request enhancements and get help through GitHub")

GitHub 저장소를 통해 기능 요청을 제출하고 Langflow에 대한 도움을 받을 수도 있습니다.
자세한 내용은 [도움 받기 및 개선 사항 요청하기](https://docs.langflow.org/contributing-github-issues)를 참고하세요.
