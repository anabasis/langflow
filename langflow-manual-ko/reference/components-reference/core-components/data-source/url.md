# URL

> 원문: https://docs.langflow.org/next/url

**URL** 컴포넌트는 하나 이상의 URL에서 콘텐츠를 가져와 처리한 뒤 다양한 형식으로 반환합니다.
지정된 깊이까지 링크를 재귀적으로 따라가며, 일반 텍스트, Markdown, 원본 HTML 형식의 출력을 지원합니다.

## URL 파라미터[​](#url-parameters "Direct link to URL parameters")

일부 파라미터는 비주얼 에디터에서 기본적으로 숨겨져 있습니다.
컴포넌트를 선택했을 때 나타나는 [컴포넌트 검사 패널](https://docs.langflow.org/concepts-components#component-inspection-panel)을 통해 모든 컴포넌트 파라미터를 수정할 수 있습니다.

사용 가능한 파라미터 중 일부는 다음과 같습니다.

| 이름             | 표시 이름    | 설명                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| urls             | URLs            | 입력 파라미터. 재귀적으로 크롤링할 하나 이상의 URL입니다. 비주얼 에디터에서 **Add URL**을 클릭하여 여러 URL을 추가할 수 있습니다.                                                                                                                                                                                                                                                                                          |
| max\_depth       | Depth           | 입력 파라미터. 링크 탐색 정도를 제어합니다. 즉 크롤러가 시작 페이지로부터 몇 "클릭" 떨어진 곳까지 이동할지를 결정합니다. 깊이 1은 지정된 URL의 첫 페이지만 크롤링하도록 제한합니다. 깊이 2는 첫 페이지와 첫 페이지에서 직접 링크된 각 페이지를 크롤링한 뒤 멈춘다는 의미입니다. 이 설정은 오직 링크 탐색만 제어하며, URL 경로 세그먼트 수나 도메인을 제한하지는 않습니다. |
| prevent\_outside | Prevent Outside | 입력 파라미터. 활성화하면 루트 URL과 동일한 도메인 내의 URL만 크롤링합니다. 크롤링된 페이지 중 하나에서 링크되어 있더라도, 지정된 URL의 도메인을 벗어난 사이트에는 크롤러가 접근하지 못하도록 방지합니다.                                                                                                                                                                                              |
| use\_async       | Use Async       | 입력 파라미터. 활성화하면 비동기 로딩을 사용하며, 이는 훨씬 빠를 수 있지만 시스템 자원을 더 많이 사용할 수 있습니다.                                                                                                                                                                                                                                                                                                     |
| format           | Output Format   | 입력 파라미터. 원하는 출력 형식을 **Text**, **Markdown**, **HTML** 중에서 설정합니다. 기본값은 **Text**입니다. 자세한 내용은 [URL 출력](#url-output)을 참고하세요.                                                                                                                                                                                                                                                        |
| timeout          | Timeout         | 입력 파라미터. 요청의 타임아웃(초)입니다.                                                                                                                                                                                                                                                                                                                                                                                |
| headers          | Headers         | 입력 파라미터. 인증 등의 목적으로 요청과 함께 전송할 헤더입니다.                                                                                                                                                                                                                                                                                                                                                          |

오류 처리 및 인코딩을 위한 추가 입력 파라미터도 제공됩니다.

## URL 출력[​](#url-output "Direct link to URL output")

**URL** 컴포넌트의 출력을 서로 다른 단계에서 제어하는 두 가지 설정이 있습니다.

- **Output Format**: 이 선택적 파라미터는 크롤링된 페이지에서 추출되는 콘텐츠를 제어합니다.

  * **Text(기본값)**: 컴포넌트는 크롤링된 페이지의 HTML에서 텍스트만 추출합니다.
  * **Markdown**: [Markitdown](https://github.com/microsoft/markitdown)을 사용하여 HTML 콘텐츠를 Markdown 형식으로 변환합니다.
  * **HTML**: 크롤링된 페이지의 전체 원본 HTML 콘텐츠를 추출합니다.

- **Output data type**: 컴포넌트의 출력 필드(출력 포트 근처)에서 다른 컴포넌트로 전달될 때의 출력 데이터 구조를 선택할 수 있습니다.

  * **Extracted Pages**: 전체 페이지 콘텐츠(`text`)와 `url`, `title` 같은 메타데이터를 컬럼으로 분리한 [`Table`](https://docs.langflow.org/data-types#table)을 출력합니다.
  * **Raw Content**: 크롤링된 페이지의 전체 텍스트, Markdown, HTML(메타데이터 포함)을 하나의 텍스트 블록으로 담은 [`Message`](https://docs.langflow.org/data-types#message)를 출력합니다.

플로우에서 표준 컴포넌트로 사용할 경우, **URL** 컴포넌트는 선택된 출력 데이터 유형을 받아들이는 컴포넌트에 연결되어야 합니다.
**URL** 컴포넌트를 호환되는 컴포넌트에 직접 연결하거나, 데이터 유형이 직접 호환되지 않는 경우 [**Type Convert** 컴포넌트](https://docs.langflow.org/type-convert)를 사용하여 출력을 다른 유형으로 변환한 뒤 다른 컴포넌트에 데이터를 전달할 수 있습니다.

**Type Convert** 컴포넌트와 같은 처리 컴포넌트는 크롤링된 페이지에서 많은 양의 데이터를 추출할 수 있는 **URL** 컴포넌트와 함께 사용하면 유용합니다.
예를 들어 특정 필드만 다른 컴포넌트로 전달하려면, [**Parser** 컴포넌트](https://docs.langflow.org/parser)를 사용하여 크롤링된 페이지에서 해당 데이터만 추출한 뒤 다른 컴포넌트로 전달할 수 있습니다.

**Agent** 컴포넌트와 함께 **Tool Mode**로 사용하는 경우, **URL** 컴포넌트는 데이터를 변환하지 않고도 **Agent** 컴포넌트의 **Tools** 포트에 직접 연결할 수 있습니다.
에이전트는 사용자 쿼리에 따라 **URL** 컴포넌트를 사용할지 여부를 결정하며, `Table` 또는 `Message` 출력을 직접 처리할 수 있습니다.
