# 현재 날짜

> 원문: https://docs.langflow.org/next/current-date

**현재 날짜(Current Date)** 컴포넌트는 선택한 시간대의 현재 날짜와 시간을 반환합니다. 이 컴포넌트는 Langflow 파이프라인 내에서 특정 시간대의 날짜 및 시간 정보를 얻을 수 있는 유연한 방법을 제공합니다.

## 현재 날짜 파라미터[​](#current-date-parameters "Current Date parameters 항목으로 바로 가기")

| Name          | Type   | Description                                                                     |
| ------------- | ------ | ------------------------------------------------------------------------------- |
| timezone      | String | 입력 파라미터. 현재 날짜와 시간에 사용할 시간대입니다.                    |
| current_date | String | 출력 파라미터. 선택한 시간대로 변환된 현재 날짜와 시간 결과입니다. |
