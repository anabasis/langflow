# 컴포넌트 개요

컴포넌트는 플로우의 기본 구성 요소입니다. 애플리케이션의 클래스처럼 각 컴포넌트는 특정 사용 사례나 통합을 위해 설계되었습니다.

---

## 플로우에 컴포넌트 추가

플로우에 컴포넌트를 추가하려면 **Core components** 또는 **Bundles** 메뉴에서 컴포넌트를 워크스페이스로 드래그합니다.

컴포넌트는 유형 또는 공급자별로 그룹화됩니다:

- **Core components**: Langflow의 기본 컴포넌트가 **Inputs and Outputs** 또는 **Data**와 같이 목적별로 그룹화됩니다.
- **Bundles**: 특정 서드파티 통합을 지원하는 하나 이상의 컴포넌트를 포함하며 서비스 제공자별로 그룹화됩니다.
- **Legacy**: 기본적으로 숨겨진 컴포넌트입니다.

---

## 컴포넌트 구성

컴포넌트를 플로우에 추가한 후 컴포넌트의 매개변수를 구성하고 플로우의 다른 컴포넌트에 연결합니다.

각 컴포넌트에는 컴포넌트 목적에 관련된 입력, 출력, 매개변수 및 컨트롤이 있습니다. 기본적으로 컴포넌트는 필수 및 공통 옵션만 표시합니다.

### 컴포넌트 검사 패널

워크스페이스에서 컴포넌트를 선택하면 화면 오른쪽에 컴포넌트 검사 패널이 나타납니다. 검사 패널에는 숨겨진 또는 고급 매개변수를 포함하여 컴포넌트의 모든 매개변수가 표시됩니다.

### 컴포넌트 헤더 메뉴

워크스페이스에서 컴포넌트를 클릭하면 헤더 메뉴가 나타납니다:

- **Code**: 컴포넌트의 Python 코드를 직접 편집하여 컴포넌트 설정을 수정합니다.
- **Freeze**: 컴포넌트와 모든 업스트림 컴포넌트를 동결하여 재실행을 방지합니다.
- **Tool Mode**: **Agent** 컴포넌트와 컴포넌트를 결합할 때 이 옵션을 활성화합니다.

### 컴포넌트 실행

단일 컴포넌트를 실행하려면 **Run component**를 클릭합니다. **Last Run** 값은 컴포넌트가 성공적으로 실행되었음을 나타냅니다.

단일 컴포넌트를 실행하는 것은 전체 플로우를 실행하는 것과 다릅니다. 단일 컴포넌트 실행에서는 비주얼 에디터를 통해 직접 제공된 입력만 있는 단일 컴포넌트만 빌드되고 실행됩니다. 전체 플로우 실행과 달리 단일 컴포넌트 실행은 업스트림 의존성을 자동으로 실행하지 않습니다.

### 컴포넌트 동결

**동결** 옵션은 컴포넌트와 모든 업스트림 컴포넌트의 일관된 출력이 예상되고 해당 컴포넌트를 한 번만 실행해야 하는 경우에 사용합니다.

---

## 컴포넌트 포트

각 컴포넌트 테두리 주변에는 원형 포트 아이콘이 있습니다. 이는 컴포넌트 *연결 지점* 또는 *포트*를 나타냅니다.

포트는 특정 데이터 타입의 입력을 허용하거나 출력을 생성합니다. 포트가 연결된 필드나 [포트 색상](#port-colors)에서 데이터 타입을 추론할 수 있습니다.

플로우를 구축할 때 동일한 유형(색상)의 입력 포트에 출력 포트를 연결하여 두 컴포넌트 간에 해당 유형의 데이터를 전송합니다.

### 동적 포트

일부 컴포넌트에는 동적으로 추가되거나 제거되는 포트가 있습니다. 예를 들어 **Prompt Template** 컴포넌트는 중괄호로 감싸진 입력을 허용하며, **Template** 필드에서 중괄호로 감싸진 값이 감지되면 새 포트가 열립니다.

### 출력 유형 선택

일부 컴포넌트는 여러 유형의 출력을 생성할 수 있습니다. 예를 들어 언어 모델 컴포넌트는 **Model Response** 또는 **Language Model**을 출력할 수 있습니다.

### 포트 색상

| 데이터 타입 | 포트 색상 |
|------------|----------|
| JSON | 빨간색 |
| Table | 분홍색 |
| Embeddings | 에메랄드 |
| LanguageModel | 자홍색 |
| Memory | 주황색 |
| Message | 남색 |
| Tool | 청록색 |
| 알 수 없거나 여러 타입 | 회색 |

## 컴포넌트 코드

비주얼 에디터에서 컴포넌트를 선택하고 **Code**를 클릭하면 컴포넌트의 기본 Python 코드를 보고 편집할 수 있습니다.

모든 컴포넌트에는 구성 방법과 수행할 수 있는 작업을 결정하는 기본 코드가 있습니다. 모든 컴포넌트는 컴포넌트의 인터페이스와 동작을 정의하는 기본 `Component` 클래스를 상속받습니다.

---

## 컴포넌트 버전

컴포넌트 버전과 상태는 내부 Langflow 데이터베이스에 저장됩니다. 플로우에 컴포넌트를 추가하면 Langflow 데이터베이스의 정보를 기반으로 컴포넌트의 분리된 복사본을 만듭니다.

### 컴포넌트 버전 업데이트

워크스페이스에서 플로우를 편집할 때 컴포넌트의 워크스페이스 버전이 데이터베이스 버전보다 오래된 경우 Langflow가 알려줍니다:

- **Update ready**: 업데이트에 주요 변경 사항이 없습니다.
- **Update available**: 업데이트에 주요 변경 사항이 있을 수 있습니다.

---

## 컴포넌트 그룹화

여러 컴포넌트를 단일 컴포넌트로 그룹화하여 재사용할 수 있습니다. 이는 관련 컴포넌트를 함께 결합하여 대규모 플로우를 정리하는 데 유용합니다.

1. `Shift`를 누른 상태로 클릭하고 드래그하여 병합할 모든 컴포넌트를 강조 표시합니다.
2. 마우스와 키보드를 놓고 **Group**을 클릭하여 컴포넌트를 단일 그룹 컴포넌트로 병합합니다.

---

## 레거시 컴포넌트

레거시 컴포넌트는 더 이상 지원되지 않으며 향후 릴리스에서 제거될 수 있습니다. 기존 플로우에서 계속 사용할 수 있지만 가능한 한 빨리 지원되는 컴포넌트로 교체하는 것을 권장합니다.

기본적으로 이 컴포넌트는 숨겨져 있습니다. 비주얼 에디터에서 **Component settings**를 클릭하여 **Legacy** 필터를 토글할 수 있습니다.
