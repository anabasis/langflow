# 플로우 빌드

*플로우*는 애플리케이션 워크플로우의 기능적 표현입니다.
플로우는 입력을 받아 처리하고 출력을 생성합니다.

플로우는 애플리케이션 워크플로우의 개별 단계를 나타내는 *컴포넌트*로 구성됩니다.

Langflow 플로우는 완전히 직렬화 가능하며, Langflow가 설치된 파일 시스템에서 저장하고 로드할 수 있습니다.

> **팁**: 몇 분 안에 플로우를 빌드하고 실행해보려면 [Langflow 빠른 시작](../get-started/quickstart.md)을 참조하세요.

---

## 플로우 만들기

[**Projects** 페이지](#프로젝트에서-플로우-관리)에서 네 가지 방법으로 플로우를 만들 수 있습니다:

- **빈 플로우 만들기**: 프로젝트를 선택하고 **New Flow**, **Blank Flow**를 클릭합니다.
- **템플릿에서 플로우 만들기**: 프로젝트를 선택하고 **New Flow**를 클릭한 후 사용할 템플릿을 클릭합니다.
- **기존 플로우 복제**: 복사할 플로우를 찾고 **More**, **Duplicate**를 클릭합니다.
- **플로우 가져오기**: [플로우 가져오기 및 내보내기](./import-export-flows.md)를 참조하세요.

**템플릿이란?**

템플릿은 자신만의 플로우를 위한 시작점으로 사용할 수 있는 사전 제작된 플로우입니다.
몇 개의 컴포넌트가 있는 기본 플로우부터 많은 컴포넌트와 하위 플로우가 있는 복잡한 플로우까지 다양합니다.

예를 들어 **Basic Prompting** 템플릿은 채팅 입력과 사전 정의된 지시(프롬프트로)를 LLM에 전달하는 소규모 플로우를 보여줍니다.

### 컴포넌트 추가

플로우는 [워크스페이스](./visual-editor.md)에서 구성하고 연결하는 노드인 [컴포넌트](../components-reference/components-overview.md)로 구성됩니다.
각 컴포넌트는 AI 모델을 서빙하거나 데이터 소스를 연결하는 등 특정 작업을 수행합니다.

**Core components** 및 **Bundles** 메뉴에서 컴포넌트를 드래그 앤 드롭하여 플로우에 추가합니다.
그런 다음 컴포넌트 설정을 구성하고 컴포넌트를 서로 연결합니다.

응집력 있는 플로우를 만들기 위해 특정 데이터 유형을 수신하거나 전송하는 *엣지* 또는 *포트*로 컴포넌트를 연결합니다.
예를 들어 메시지 포트는 컴포넌트 간에 텍스트 문자열을 전송합니다.

### 플로우 실행

프로토타입 플로우를 빌드한 후 [**플레이그라운드**](./test-flows.md)에서 테스트할 수 있습니다.
애플리케이션 개발에 Langflow를 사용할 준비가 되면 [Langflow API로 플로우를 트리거](./run-flows.md)하는 방법을 알아보세요.

#### 플로우 그래프

플로우가 실행될 때, Langflow는 노드(컴포넌트)와 엣지(연결)로부터 방향 비순환 그래프(DAG) 객체를 빌드하고, 노드는 실행 순서를 결정하기 위해 정렬됩니다.

그래프 빌드는 각 컴포넌트의 `def_build` 함수를 호출하여 노드를 유효성 검사하고 준비합니다.
이 그래프는 종속성 순서에 따라 처리됩니다.
각 노드는 순차적으로 빌드 및 실행되며, 각 빌드된 노드의 결과가 해당 노드의 결과에 종속된 노드에 전달됩니다.

## 프로젝트에서 플로우 관리

**Projects** 페이지는 Langflow를 실행할 때 도착하는 곳입니다.
여기서 플로우와 프로젝트의 [MCP 서버](../mcp/mcp-server.md)를 관리할 수 있습니다.

Langflow 프로젝트는 관련 플로우를 정리하는 데 사용할 수 있는 폴더와 같습니다.
기본 프로젝트는 **Starter Project**이며, 다른 프로젝트를 만들지 않는 한 여기에 플로우가 저장됩니다.
프로젝트를 만들려면 **Create new project**를 클릭합니다.

### 플로우 세부 정보 편집

1. **Projects** 페이지에서 편집할 플로우를 찾습니다.
2. **More**, **Edit details**를 클릭합니다.
3. **Name**과 **Description**을 편집한 후 **Save**를 클릭합니다.

### 플로우 버전 저장 및 복원

플로우 편집기의 **Version History** 메뉴에서 플로우의 버전을 저장할 수 있습니다.

1. 버전을 만들 플로우를 엽니다.
2. 플로우 편집기 사이드바에서 **Version History**를 클릭합니다.
3. **Current**에서 **Save**를 클릭하여 플로우의 현재 상태를 저장된 버전으로 캡처합니다.
4. 이전에 저장된 버전을 선택하여 읽기 전용 모드로 플로우를 미리 봅니다.
5. 선택한 버전으로 현재 초안을 교체하려면 **Restore**를 클릭합니다.

저장된 버전의 메뉴에서 해당 버전을 **Export** 또는 **Delete**할 수도 있습니다.

### 플로우 잠금

플로우 변경을 방지하려면 잠글 수 있습니다:

1. **Projects** 페이지에서 잠글 플로우를 찾습니다.
2. **More**, **Edit details**를 클릭합니다.
3. **Lock Flow**를 활성화하고 **Save**를 클릭합니다.

같은 단계를 반복하여 **Lock Flow**를 비활성화하면 플로우 잠금을 해제할 수 있습니다.

### 플로우 이동

플로우를 한 프로젝트에서 다른 프로젝트로 이동하려면:

1. **Projects** 페이지에서 이동할 플로우를 찾습니다.
2. 플로우 목록에서 대상 프로젝트 이름으로 플로우를 클릭하고 드래그합니다.

### 플로우 삭제

1. **Projects** 페이지에서 삭제할 플로우를 찾습니다.
2. **More**, **Delete**를 클릭합니다.

## 플로우 저장 및 로그

기본적으로 플로우와 플로우 실행 데이터는 Langflow 데이터베이스에 저장되고, 플로우 로그는 Langflow 구성 디렉토리의 다른 Langflow 로그와 함께 저장됩니다.
