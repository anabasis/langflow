# Langflow 커뮤니티 참여

Langflow 커뮤니티와 상호작용하고 Langflow 코드베이스에 대해 더 배울 수 있는 여러 방법이 있습니다.

---

## Langflow Discord 서버 참여

[Langflow Discord 서버](https://discord.gg/EqksyE2EX9)에 참여하여 질문하고 프로젝트를 공유합니다.

---

## X에서 Langflow 팔로우

[@langflow_ai](https://twitter.com/langflow_ai)를 X에서 팔로우하여 Langflow에 대한 최신 소식을 확인합니다.

---

## GitHub에서 Langflow에 별표 주기

Langflow가 마음에 든다면 [Langflow GitHub 저장소](https://github.com/langflow-ai/langflow)에 별표를 줄 수 있습니다. 별표는 다른 사용자가 Langflow를 더 쉽게 찾을 수 있게 도와줍니다.

---

## GitHub 저장소 감시

[Langflow GitHub 저장소](https://github.com/langflow-ai/langflow)를 감시하여 새 릴리스 및 기타 저장소 활동에 대한 알림을 받을 수 있습니다.

새 릴리스 알림만 받으려면 **Releases only**를 선택합니다.

---

## GitHub을 통한 기능 요청 및 도움 받기

GitHub 저장소를 통해 기능 요청을 제출하고 Langflow 도움을 받을 수 있습니다.

---
