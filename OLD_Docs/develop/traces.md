# 추적 (Traces)

Langflow의 **추적(Traces)** 기능은 플로우와 컴포넌트에 대한 상세한 실행 추적을 기록하여 외부 관찰 가능성 서비스에 의존하지 않고도 문제를 디버그하고, 지연 시간을 측정하며, 토큰 사용량을 추적할 수 있습니다.

추적 데이터는 Langflow 데이터베이스의 `trace` 및 `span` 테이블에 저장됩니다. 추적 데이터는 UI의 **Flow Activity** 및 **Trace Details** 페이지에 표시되고, `/monitor/traces` API 엔드포인트에서 검색할 수 있습니다.

추적은 기본적으로 활성화되어 있습니다. Langflow 추적을 비활성화하고 다른 추적 제공자를 사용하려면 `LANGFLOW_NATIVE_TRACING`를 `false`로 설정합니다.

---

## 추적에 캡처되는 내용

추적기가 기록하는 내용:

- **플로우 수준 추적**: 각 플로우 실행에 대한 추적 (총 실행 시간 및 상태 포함)
- **컴포넌트 스팬**: 플로우 내 각 컴포넌트의 스팬 (입력, 출력, 지연 시간, 오류 포함)
- **LangChain 스팬**: 체인, 도구, 검색기, LLM 호출에 대한 더 깊은 스팬 (모델 이름 및 토큰 사용량 포함)

각 스팬에 포함되는 내용:

- **이름**과 **유형** (예: 체인, LLM, 도구, 검색기)
- **시작 및 종료 시간**과 **지연 시간(ms)**
- **입력 및 출력** (직렬화됨)
- 스팬이 실패한 경우 **오류 세부 정보**
- 토큰 수 및 모델 메타데이터와 같은 **속성**

---

## UI에서 추적 보기

1. 플로우를 실행합니다 (예: [빠른 시작](../get-started/quickstart.md)의 Simple Agent 스타터 플로우).

2. **Traces**를 클릭합니다. **Flow Activity** 페이지가 열립니다. 각 플로우 실행은 모든 스팬의 단일 추적으로 표시됩니다. 세션 ID, 상태 또는 시간 범위별로 더 정렬할 수 있습니다. 선택적으로 **Download**를 클릭하여 추적의 JSON 파일을 다운로드합니다.

3. 플로우 실행을 클릭하여 **Trace Details** 창을 엽니다. 전체 실행에 대한 플로우 수준 스팬과 각 컴포넌트에 대한 스팬이 표시됩니다.

## API로 추적 검색

추적을 프로그래밍 방식으로 쿼리하려면 `/monitor/traces` 엔드포인트를 사용합니다. 자세한 내용은 [모니터 엔드포인트: 추적 가져오기](../api-reference/api-monitor.md)를 참조하세요.
